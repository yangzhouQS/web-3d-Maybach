# 📋 实施偏差与决策记录（审查重点）
| # | 计划 | 实际 | 原因 |
|---|---|---|---|
| 1 | typescript 最新版 | **锁定 `~5.9.3`（package.json 锁区间 + engines 声明）** | TS 7（原生版）包结构变化，vue-tsc 3.x 不兼容（`./lib/tsc` 子路径失效）；已注释于 README |
| 2 | 依赖 uuid | **改用 crypto.randomUUID（含降级兜底 genId）** | 浏览器原生支持，减少一个依赖，防御旧环境 |
| 3 | lil-gui 静态引入 | **动态 import + DEV 守卫** | 确保生产包物理移除（已验证产物无 lil-gui） |
| 4 | 模型是阶段3前置阻塞项 | **新增程序化占位模型兜底** | 真实 GLB 未交付；占位车命名严格对齐附录 A，切换真实模型零改动；画布左下角常驻「占位模型」标识 + 零匹配命名警告；可通过 modelConfig.allowFallback 关闭 |
| 5 | useScreenshot.ts hook | **utils/screenshot.ts 工具函数** | 无自身状态，函数式更简洁 |
| 6 | PresetColorGroup / ViewPresetBtn 独立组件 | **已拆分：`components/panel/ColorPresetGroup.tsx`、`components/panel/ViewPresetButtons.tsx`** | 优化阶段还原计划结构，主面板文件瘦身 |
| 7 | OutlinePass hover 呼吸闪烁 | **限时呼吸脉冲（yoyo×2，约1.2s 后回归静态描边）** | 兼顾 SRS 呼吸反馈与 §2.4-5 停帧原则：脉冲期间逐帧 requestRender，结束即停帧 |
| 8 | 消息走组件树 Provider | **createDiscreteApi** | 任意层直接调用，TSX 场景更简洁 |
| 9 | 预设配色作用于「选中部件」 | **按预设内命名部件映射 + 材质参数应用到选中（无选中则应用预设涉及部件）** | 双拼双色等预设需按部件精确赋色，与 SRS FR05-01 语义一致且更可控 |
